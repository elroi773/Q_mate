# Qmate

> AI를 활용해 상황별 맞춤형 모의 면접 연습을 제공하는 웹사이트 플랫폼

## 프로젝트 소개

**Qmate**는 미림 소프트웨어 챌린지 개발 분야 출품 작품으로, 학생들이 다양한 면접 상황을 실제처럼 연습할 수 있도록 돕는 AI 기반 모의 면접 플랫폼입니다.

기존 모의 면접 서비스가 주로 기업 취업 면접에 집중되어 있다는 점에서 출발하여, 고등학생·대학생·특수 면접 준비생 등 다양한 학습자를 위한 맞춤형 면접 연습 환경을 제공하는 것을 목표로 합니다.

---

## 아이디어 배경

### 1. 개인적 경험

미림 마이스터고등학교 입학 후 여러 면접 상황을 경험하면서, 학생을 위한 실전형 면접 연습 서비스의 필요성을 느꼈습니다.

- 입학 면접
- 전공 동아리 면접
- 글로벌 인턴십 면접

### 2. 현재 문제점

#### 기존 서비스의 한계

- 대부분의 모의 면접 서비스가 기업 취업 중심으로 구성되어 있음
- 학생이나 특수한 상황의 면접 수요를 충분히 반영하지 못함

#### 학습자의 어려움

- 실제 면접에서 긴장과 불안으로 인해 역량 발휘가 어려움
- 연습 기회가 부족하고 객관적인 피드백을 받기 어려움
- 반복적인 면접 연습 환경을 스스로 구축하기 어려움

### 3. 시장 기회

- 고등학생, 대학생, 특수 면접 준비생 등 대상 확장 가능
- AI 기술 발전으로 개인화된 피드백 제공 가능
- 교육 서비스 시장의 지속적인 성장
- 비대면 학습 환경 확대에 따른 온라인 모의 면접 수요 증가

---

## 서비스 개요

Qmate는 사용자의 목표와 상황에 맞춰 면접 질문을 제공하고, 답변 이후 AI 기반 피드백을 제공하는 모의 면접 플랫폼입니다.

### 주요 기능

- 학습 대상 맞춤형 모의 면접 제공
- 사용자 목표에 따른 맞춤 질문 생성
- 답변 후 즉각적인 AI 피드백 제공
- 면접 기록 저장 및 반복 학습 지원
- 개인별 약점 분석 및 개선 방향 제시

---

## 주요 효과

### 현실적인 면접 경험 제공

실제 면접과 유사한 질문과 환경을 제공하여 사용자의 긴장을 완화하고 면접 적응력을 높일 수 있습니다.

### 맞춤형 면접 대비

사용자의 목표에 따라 질문이 달라지기 때문에 개인별 상황에 맞는 특화된 면접 훈련이 가능합니다.

### 객관적인 피드백 제공

AI 분석을 기반으로 답변의 길이, 논리성, 태도, 표현력 등을 평가하여 사용자가 자신의 부족한 부분을 확인할 수 있습니다.

### 자신감 향상

반복적인 면접 연습을 통해 불안감을 줄이고, 성취감을 얻으며 면접 자신감을 높일 수 있습니다.

## 예상되는 문제점 및 해결 방향

### Frontend

#### 1. AI 피드백 시각화의 복잡성

AI 분석 결과를 단순 텍스트로만 제공하면 몰입도가 낮아질 수 있습니다.  
따라서 점수화, 차트, 아이콘 등을 활용한 직관적인 피드백 UI를 고려합니다.

#### 2. 실시간 상호작용 처리 문제

질문과 답변이 자연스럽게 이어져야 실제 면접과 유사한 경험을 줄 수 있습니다.  
API 응답 지연으로 UX가 저하되지 않도록 로딩 처리와 비동기 흐름을 고려합니다.

#### 3. 반응형 및 접근성 문제

PC, 모바일, 태블릿 등 다양한 환경에서 UI가 깨지지 않도록 반응형 레이아웃을 적용합니다.  
음성 답변 기능은 모바일 환경에서도 정상적으로 작동하는지 테스트가 필요합니다.

#### 4. 상태 관리 복잡성 증가

질문, 답변, 피드백 데이터를 여러 페이지에서 공유해야 하므로 상태 관리 구조를 명확히 설계해야 합니다.  
잘못 구현할 경우 데이터 불일치 문제가 발생할 수 있습니다.

---

### Backend

#### 1. AI API 사용 비용

사용자 수가 증가하면 AI API 호출 비용이 빠르게 증가할 수 있습니다.  
이를 줄이기 위해 질문 캐싱, 자주 사용되는 질문 미리 생성, 호출 최적화 전략을 고려합니다.

#### 2. 실시간 응답 지연

AI 응답 속도가 느릴 경우 면접 흐름이 끊길 수 있습니다.  
비동기 처리, 큐 시스템, WebSocket 적용 등을 검토합니다.

#### 3. 분석 데이터 처리 부담

음성 인식과 표정 분석 등 멀티미디어 처리는 서버 부하가 커질 수 있습니다.  
브라우저 단 처리, WebRTC 활용, 경량화 모델 적용 등을 고려합니다.

## 프로젝트 목표

Qmate는 학생들이 면접에 대한 부담을 줄이고, 반복적인 연습과 AI 피드백을 통해 실질적인 면접 역량을 향상할 수 있도록 돕는 것을 목표로 합니다.

단순한 질문 제공 서비스를 넘어, 사용자의 답변 데이터를 기반으로 성장 과정을 기록하고 맞춤형 학습 방향을 제시하는 AI 면접 연습 플랫폼으로 발전시키고자 합니다.
